One sample record per unique LUCAS sampling point — a fixed 0–20 cm topsoil profile, linked to
its geolocation and to the campaign's sampling log.

## Prerequisites

- [Manage geolocation] must be complete.

## Notebook cell

In `load_LUCAS.ipynb`, the **Manage LUCAS samples** cell runs:

```python
job_file = 'import_data/LUCAS_2009/job_LUCAS_2009_sample.json'

structured_process_D, scheme_params_D = Initiate_process(notebook_path, scheme_file, job_file)

if structured_process_D is not None:
    Run_process(structured_process_D, scheme_params_D)
```

## Job file

**Path**: `xspatula_lucas/lucas/import_data/LUCAS_2009/job_LUCAS_2009_sample.json`

```json
{
  "process": {
    "job_folder": "import_data/LUCAS_2009/process_lab/sample",
    "process_sub_folder": "manage_process",
    "pilot_file": "xspatula_add_sample_pilot.txt"
  }
}
```

## Pilot file and process files

**Generated by**: `lucas_2009_to_xspatula.py`, `step5_sample()`

**Path**: `.../process_lab/sample/xspatula_add_sample_pilot.txt` — one entry per unique `POINT_ID`.

Each process file (`.../process_lab/sample/manage_process/lucas_eu_2009_<POINT_ID>_0_20_sample.json`):

```json
{
  "process": [
    {
      "process": "manage_geolocated_profile_sample",
      "parameters": {
        "sampling_log_id__sampling_log_name": "lucas_eu_2009",
        "tag": "<POINT_ID>",
        "name": "<POINT_ID>@0-20",
        "sampled_at": "<SURV_DATE, as YYYYMMDD>",
        "species_id__species_name": "soil",
        "geolocation_id__geolocation_name": "<iso_country>_lucas@<POINT_ID>",
        "profile_min": 0,
        "profile_max": 20,
        "juxtaposition_id__juxtaposition_name": "uniform",
        "proximity_id__proximity_name": "general",
        "composition_id__composition_name": "composite"
      }
    }
  ]
}
```

## Parameters

| Parameter | Source | Description |
|---|---|---|
| `sampling_log_id__sampling_log_name` | fixed | `lucas_eu_2009` — the campaign's sampling log |
| `tag` | `POINT_ID` | Raw LUCAS point identifier |
| `name` | `POINT_ID` | Sample name, format `<point_id>@0-20` |
| `sampled_at` | `SURV_DATE` | Converted from LUCAS's `DDMONYYYY` format to `YYYYMMDD` |
| `geolocation_id__geolocation_name` | derived | FK to the [geolocation][Manage geolocation] record for the same point |
| `profile_min` / `profile_max` | fixed | `0` / `20` — LUCAS 2009 topsoil samples are all 0–20 cm |
| `juxtaposition_id__juxtaposition_name` | fixed | `uniform` |
| `proximity_id__proximity_name` | fixed | `general` |
| `composition_id__composition_name` | fixed | `composite` |

The `name` value (`<point_id>@0-20`) is the foreign key referenced by `sample_id__sample_name` in
both the [lab][load_campaign] and [spectral][Manage observation] observation records for the same
point.
