One geolocation record per unique LUCAS sampling point, generated directly from the source CSV's
GPS columns — no Excel intermediary.

## Prerequisites

- The campaign and sampling log steps in [LUCAS 2009 → Load campaign][load_campaign] must be
  complete.
- The source CSV must already be processed by `lucas_2009_to_xspatula.py` — see
  [Prepare data][prepare_data].

## Notebook cell

In `load_LUCAS.ipynb`, the **Manage LUCAS geolocations** cell runs:

```python
job_file = 'import_data/LUCAS_2009/job_LUCAS_2009_geolocation.json'

structured_process_D, scheme_params_D = Initiate_process(notebook_path, scheme_file, job_file)

if structured_process_D is not None:
    Run_process(structured_process_D, scheme_params_D)
```

## Job file

**Path**: `xspatula_lucas/lucas/import_data/LUCAS_2009/job_LUCAS_2009_geolocation.json`

```json
{
  "process": {
    "job_folder": "import_data/LUCAS_2009/process_lab/geolocation",
    "process_sub_folder": "manage_process",
    "pilot_file": "xspatula_add_geolocation_pilot.txt"
  }
}
```

## Pilot file and process files

**Generated by**: `lucas_2009_to_xspatula.py`, `step4_geolocation()`

**Path**: `.../process_lab/geolocation/xspatula_add_geolocation_pilot.txt` — one entry per unique
`POINT_ID`.

Each process file (`.../process_lab/geolocation/manage_process/<name>_geolocation.json`):

```json
{
  "process": [
    {
      "process": "manage_geolocation",
      "parameters": {
        "name": "<iso_country>_lucas@<POINT_ID>",
        "x_coordinate": "<GPS_LONG>",
        "y_coordinate": "<GPS_LAT>"
      }
    }
  ]
}
```

## Parameters

| Parameter | Source | Description |
|---|---|---|
| `name` | `iso.country` + `POINT_ID` | Naming pattern: `<iso_country>_lucas@<point_id>`, e.g. `se_lucas@48383012` |
| `x_coordinate` | `GPS_LONG` | Longitude |
| `y_coordinate` | `GPS_LAT` | Latitude |

This `name` value is the foreign key referenced by `geolocation_id__geolocation_name` in the
[sample][Manage sample] record for the same point.
