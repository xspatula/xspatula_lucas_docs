One spectrometer record registers the instrument's wavelength axis — the array of wavelengths
each spectral observation's reflectance array is ordered against.

## Notebook cell

In `load_LUCAS.ipynb`, the **Manage LUCAS spectrometer** cell runs:

```python
job_file = 'import_data/LUCAS_2009/job_LUCAS_2009_spectrometer.json'

structured_process_D, scheme_params_D = Initiate_process(notebook_path, scheme_file, job_file)

if structured_process_D is not None:
    Run_process(structured_process_D, scheme_params_D)
```

## Job file

**Path**: `xspatula_lucas/lucas/import_data/LUCAS_2009/job_LUCAS_2009_spectrometer.json`

## Process file

**Generated by**: `lucas_2009_to_xspatula.py`, `step3_spectrometer()`

**Path**: `.../process_spectra/spectrometer/manage_process/foss-xds-rca_lucas 2009_spectrometer.json`

```json
{
  "process": [
    {
      "process": "manage_spectrometer",
      "parameters": {
        "provision_id__provision_name": "foss xds rca",
        "wavelength_array": ["<one float per spc.* column in the source CSV>"],
        "wavelength_unit_id__wavelength_unit_name": "um",
        "provision_serial_nr_id__provision_serial_nr_name": "lucas 2009"
      }
    }
  ]
}
```

## Parameters

| Parameter | Description |
|---|---|
| `provision_id__provision_name` | `foss xds rca` — the instrument provision |
| `wavelength_array` | One value per `spc.<wavelength>` column in `LUCAS.SOIL_corr.csv`, in file column order |
| `wavelength_unit_id__wavelength_unit_name` | `um` |
| `provision_serial_nr_id__provision_serial_nr_name` | `lucas 2009` — placeholder serial number, since LUCAS 2009 used multiple physical instruments across labs |

The wavelength array's column order defines the position each value in an
[observation][Manage observation]'s `@diffuse reflectance` array corresponds to — they must stay
in lockstep.
