One observation record per sample — a diffuse-reflectance array derived from the source CSV's
`spc.*` absorbance columns.

## Prerequisites

- [Manage observation log] must be complete.
- [Sample][sample] loading must be complete.

## Notebook cell

In `load_LUCAS.ipynb`, the **Manage LUCAS spectra observations** cell runs:

```python
job_file = 'import_data/LUCAS_2009/job_LUCAS_2009_observation_spectra.json'
structured_process_D, scheme_params_D = Initiate_process(notebook_path, scheme_file, job_file)

if structured_process_D is not None:
    Run_process(structured_process_D, scheme_params_D)
```

## Job file

**Path**: `xspatula_lucas/lucas/import_data/LUCAS_2009/job_LUCAS_2009_observation_spectra.json`

```json
{
  "process": {
    "job_folder": "import_data/LUCAS_2009/process_spectra/observation",
    "process_sub_folder": "manage_process",
    "pilot_file": "xspatula_add_observation_pilot.txt"
  }
}
```

## Pilot file and process files

**Generated by**: `lucas_2009_to_xspatula.py`, `step7_spectra_observation()`

**Path**: `.../process_spectra/observation/xspatula_add_observation_pilot.txt` — one entry per
sample row in the source CSV.

Each process file
(`.../process_spectra/observation/manage_process/lucas_eu_2009@foss xds rca_<POINT_ID>@0-20_a_0_none_<date>_observation.json`):

```json
{
  "process": [
    {
      "process": "manage_observation",
      "parameters": {
        "observation_log_id__observation_log_name": "lucas_eu_2009@foss xds rca",
        "sample_id__sample_name": "<POINT_ID>@0-20",
        "provision_id__provision_name": "foss xds rca",
        "subsample": "a",
        "replicate": 0,
        "observed_at": "<date, ISO 8601>",
        "provision_serial_nr_id__provision_serial_nr_name": "lucas 2009",
        "@diffuse reflectance": ["<one float per spc.* column, 1/exp(absorbance)>"]
      }
    }
  ]
}
```

## Parameters

| Parameter | Source | Description |
|---|---|---|
| `observation_log_id__observation_log_name` | fixed | FK to [observation log][Manage observation log] |
| `sample_id__sample_name` | `POINT_ID` | FK to the [sample][sample] record (format `<point_id>@0-20`) |
| `provision_id__provision_name` | fixed | `foss xds rca` |
| `subsample` / `replicate` | fixed | `a` / `0` — LUCAS 2009 ships one scan per sample |
| `observed_at` | `date` column | ISO 8601 timestamp |
| `provision_serial_nr_id__provision_serial_nr_name` | fixed | FK to the [spectrometer][Manage spectrometer] serial record |
| `@diffuse reflectance` | `spc.*` columns | Reflectance array, one value per wavelength in the [spectrometer][Manage spectrometer]'s `wavelength_array`, computed as `1 / exp(absorbance)` from the CSV's raw values |

The `@diffuse reflectance` array's column order must match the spectrometer's `wavelength_array`
exactly — both are built from the same `spc.*` column iteration in the source CSV, so this holds
as long as the script isn't modified to reorder one independently of the other.
